# ZERMEY: JACK'S LAST SAFEHOUSE

A complete third-person survival game where you control Jack, a kid surviving a zombie apocalypse.

## 🎮 Game Features

### Core Gameplay
- **Third-Person Survival**: Control Jack from behind and above
- **Zombie Combat**: Punch zombies with responsive combat mechanics
- **Location Restoration**: Clear all zombies from 3 major locations to save the town
- **Health System**: Manage Jack's health and use items to survive
- **Day/Night Cycle**: Dynamic lighting changes throughout the game
- **Safe Zones**: Restore locations to create safe havens where health regenerates

### Main Locations
1. **Treehouse (Spawn)** - Your safe starting zone
2. **Abandoned Walmart** - Large infested building with many zombies
3. **Abandoned McDonald's** - Iconic location to restore
4. **Neighborhood** - Residential area with scattered zombies

### Zombie Types
- **Normal Zombies**: Standard slow followers (1 punch to defeat)
- **Fast Zombies**: Quicker but weaker (1 punch)
- **Strong Zombies**: Slow but tough (3 punches)
- **Licensed Zombie Models**: Local Quaternius Zombie Apocalypse Kit glTF enemies with animation fallback to procedural meshes if model loading fails

### Systems
- **Inventory System**: Collect food, medkits, batteries, and building materials
- **Save System**: Auto-save your progress
- **Map System**: Track locations and progress
- **Audio System**: Atmospheric music and sound effects
- **Multiplayer Support**: Join or create rooms (when networking available)

## 🚀 How to Play

1. **Start at the Treehouse** - Your safe zone where health regenerates
2. **Explore the Town** - Head to Walmart, McDonald's, or the Neighborhood
3. **Clear Zombies** - Punch every zombie in a location to restore it
4. **Collect Items** - Find food and medkits to stay alive
5. **Victory!** - Restore all 3 locations to save the town
